# Git Practice Article
[Link:] (https://www.webpronews.com/ai-makes-coding-cheap-but-reliable-software-remains-costly/)

**What's interesting is that it flips the usual hype. Instead of arguing that AI will make software development cheap across the board, it separates writing code from building software. AI has made it possible for even beginners to produce working scripts in minutes, but building reliable, scalable software is still expensive and high-stakes. The article draws on developer Chris Gregori, who argues that the hard parts are strategic architecture, rigorous testing, user-centric design, and ongoing maintenance, which AI can't fully automate yet.**

### Comments and Implications (Lokeswar Gopikrishna)
The author raises important points about being able to problem solve in the age of AI. I think this is especially important since we have to be able to direct these systems into doing what we want, and also be competent enough to identify errors in their work. Perhaps it is now important to consider the way in which computer science as a subject is taught in universities. We might benefit from a curriculum restructuring that centers on problem solving and theory rather than the practical skill of coding, which clearly seems to be done more efficiently by AI. This will also help guide innovation in the right direction and ensure that future leaders are the ones innovating with original creativity, not AI with its unoriginal repetitiveness.
